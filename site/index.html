Markdown for Everyone — the Guide

Plain-English manual teaching Markdown as a life skill: notes, to-do lists, resumes, READMEs, and simple docs — learned in nine tiny lessons. Written the way a friend would explain, step by step, never condescending.

Read it here

Nine tiny lessons, in order:

  1. What is Markdown? — the one-sentence definition
  2. Headings and paragraphs — giving notes shape
  3. Bold, italic, emphasis — the pointing finger
  4. Lists — bullets, numbers, nesting
  5. To-do checkboxes — no app required
  6. Tables — track anything in a grid
  7. Links and images — reach out from your file
  8. Quotes, code, extras — the finishing kit
  9. Real-life documents — weekly plans, resumes, READMEs

How to use this folder

  • Just read: open the lesson files above — they render on GitHub, in VS Code preview, Obsidian, or any Markdown reader.
  • Or use the HTML site: open site/index.html in any browser. Fully offline, no JavaScript needed, no tracking, no build step.
  • Take the lessons: every lesson ends with a 3-item Try it now list. Do it in notes.md as you go.

A note on privacy

Everything in this guide is designed to be read, saved, and worked through locally. No accounts, no telemetry, no "please sign in." Your notes.md and your weekly plan stay on your device.
