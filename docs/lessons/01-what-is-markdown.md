# Lesson 1 — What Is Markdown? (and Why Bother)

Welcome! This guide teaches Markdown the way a friend would: plain English,
one small step at a time, never condescending. By the end of nine tiny
lessons you'll use Markdown for everyday life — not just programming.

## The one-sentence definition

**Markdown is a way of adding simple formatting to plain text using ordinary
keyboard characters.**

That's it. You type `#` before a line to make it a title. You wrap words in
`**asterisks**` to make them **bold**. No special software, no menus, no
formatting that breaks when you copy it somewhere else.

## Markdown vs. plain text vs. Word

| | Plain text (.txt) | Markdown (.md) | Word processor (.docx) |
| --- | --- | --- | --- |
| Opens anywhere | Yes | Yes | Needs the app |
| Looks good in GitHub/Git | Not really | Yes | No |
| Copying between apps | Loses structure | Keeps structure | Gets messy |
| Learning curve | None | ~1 hour | Ongoing |

A Word file exists *inside* Microsoft Word. A Markdown file is just text —
it will still open in forty years, on any device, in any editor.

## Where you'll meet Markdown

Real places you'll actually use it:

- **GitHub** — every project's README, every issue, every pull request
- **Notes apps** — Obsidian, Joplin, Notion, Apple Notes (partly), Zettlr
- **Docs systems** — Wikipedia-style wikis, Read the Docs, developer docs
- **Email newsletters** — many feeds accept Markdown directly
- **AI chat** — most assistants write back in Markdown

## Your very first Markdown

Open any plain-text editor (Notepad on Windows, TextEdit
set to plain text on Mac, or a notes app) and type this:

```markdown
# My First Note

This is my **first** Markdown note. I made it with *just text*.

## Why I'm trying this

- It's simple
- It never breaks
- It works everywhere
```

Save it as `my-first-note.md`. Now open it on GitHub, in Obsidian, or paste
it into almost any notes app — you'll see real formatting. Those `#` marks
and `**` pairs were instructions all along.

## The big idea to carry forward

Markdown is a *life skill*, not a programmer tool. The same skill lets
you write a to-do list, a resume draft, a project README, or a recipe
collection. You type the characters you'll learn in the next eight
lessons once, and you've unlocked dozens of everyday documents.

## Try it now

1. Create a file called `notes.md`.
2. Write one `#` heading with your name.
3. Write one sentence with something **bold** in it.
4. Save it. Congratulations — you're writing Markdown.
