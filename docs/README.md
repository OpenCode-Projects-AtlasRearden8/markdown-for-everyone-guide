# Markdown for Everyone — the Guide

Plain-English manual teaching Markdown as a *life skill*: notes, to-do
lists, resumes, READMEs, and simple docs — learned in nine tiny
lessons. Written the way a friend would explain, step by step, never
condescending.

## Read it here

Nine tiny lessons, in order:

1. [What is Markdown?](lessons/01-what-is-markdown.md) — the one-sentence definition
2. [Headings and paragraphs](lessons/02-headings-and-paragraphs.md) — giving notes shape
3. [Bold, italic, emphasis](lessons/03-bold-italic-and-emphasis.md) — the pointing finger
4. [Lists](lessons/04-lists.md) — bullets, numbers, nesting
5. [To-do checkboxes](lessons/05-todo-checkboxes.md) — no app required
6. [Tables](lessons/06-tables.md) — track anything in a grid
7. [Links and images](lessons/07-links-and-images.md) — reach out from your file
8. [Quotes, code, extras](lessons/08-quotes-code-and-extras.md) — the finishing kit
9. [Real-life documents](lessons/09-real-life-documents.md) — weekly plans, resumes, READMEs

And the reference material:

- [One-page cheat sheet](cheat-sheet.md) — print this
- [Common-mistakes gallery](common-mistakes.md) — 10 traps + a debug checklist

Two hands-on walkthroughs:

- [A weekly plan with checkboxes](walkthroughs/checkboxes-week-plan.md)
- [A gear-inventory table](walkthroughs/table-gear-inventory.md)

## How to use this folder

- **Just read:** open the lesson files above — they render on GitHub,
  in VS Code preview, Obsidian, or any Markdown reader.
- **Or use the HTML site:** open `site/index.html` in any browser.
  Fully offline, no JavaScript needed, no tracking, no build step.
- **Take the lessons:** every lesson ends with a 3-item *Try it now*
  list. Do it in `notes.md` as you go.

## A note on privacy

Everything in this guide is designed to be read, saved, and worked
through **locally**. No accounts, no telemetry, no "please sign in."
Your `notes.md` and your weekly plan stay on your device.
